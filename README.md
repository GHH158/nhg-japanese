# 对日软件需求定义与分析设计场景智能研习平台 (Japanese Learning Hub)

面向对日软件工程与IT商务场景的沉浸式日语研习系统。基于实际工程教材与权威配套练习对话构建，全场景原生配备平假名振假名（`<ruby>`）注音与对日 IT 商务精准中文释义。

## ✨ 核心特性

- 🎯 **多场景沉浸式研习**：已收录场景 1、场景 2、场景 11、场景 12、场景 21 等核心对话，各场景涵盖核心主课文与 5 篇典型业务场景练习短文。
- 🇯🇵 **智能汉字假名注音**：基于 macOS 原生 NLP 分词深度标注平假名 `<ruby>` 标签，支持一键切换假名显隐，扫清生词与专业词汇阅读障碍。
- 💼 **对日 IT 专业译文**：彻底告别生硬机翻，结合需求规格说明、基本设计、详细设计、接口定义、DB设计与系统联调等对日软件工程实务精准传神翻译。
- 🔍 **多维度即时检索**：支持快速检索业务短语、专业语法、词汇与注音。
- 📱 **移动端全适配**：采用现代响应式卡片流与微交互动效设计，手机端/电脑端均能随时随地高效复习。
- 🚀 **Cloudflare Pages 自动化部署**：纯前端静态架构，GitHub 代码推送即刻毫秒级全球 CDN 自动更新。
